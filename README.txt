NU Student Portal — front-end recreation

HOW TO OPEN
1. Extract the ZIP archive.
2. Open the nu_student_portal folder.
3. Double-click index.html, or open the folder in VS Code and run it with Live Server.

FILES
- index.html: page structure
- style.css: layout, colors, responsive styles
- script.js: menu, tabs, collapsible categories and demo payment dialog
- assets/student-photo.jpg: portrait cropped from the screenshot you supplied

NOTES
This is a front-end visual recreation for learning/demo purposes. It is not connected
to Nazarbayev University's systems. Login, logout, payment processing, student records,
and official documents are not real. The name and ID shown are sample text copied from
the screenshot; edit them in index.html if needed.
